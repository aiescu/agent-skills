# Packaging and dependencies

Other named Superpowers skills remain composable companion-skill dependencies; install the suite for the complete workflow.

Optional visual companion requires Node.js and a browser; its scripts are preserved and were not executed.

Visual companion opt-outs are preserved: SUPERPOWERS_DISABLE_TELEMETRY, DISABLE_TELEMETRY, CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC.

Repository-level version manifests are not required runtime assets; isolated visual companion may display version unknown.
