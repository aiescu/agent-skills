# Packaging and dependencies

Only MIT skill/adoption content included; no BSL engine, binaries, gateway, MCP server, browser runtime or memory core is redistributed.

Some operations require an independently installed Caveman CLI, authenticated Caveman Cloud/MCP, or upstream documentation origin. Those external services/runtimes are not bundled.

Original upstream repository-oriented tests and package metadata are preserved as source; they were not executed and may assume the upstream checkout layout.
