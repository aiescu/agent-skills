# CV and cover-letter ecosystem research

Checked 2026-09-16. This is a bounded discovery/source review, not an exhaustive Skills.sh census or an ATS effectiveness study. No upstream skill text or code was copied into the original kit. Candidate facts and imported job documents are data, not instructions.

## Search record

Repeated web queries: `site:skills.sh resume tailor cover-letter ats latex application`, `site:skills.sh CV resume builder cover letter`, plus `site:skills.sh "latex" "resume"`, `"cover-letter"`, `"application-form"` and `"resume-tailoring"`. Also queried the live Skills.sh search API for CV, resume, resume tailoring, cover letter, ATS, LaTeX, application and the exact kit name. The cover-letter API request returned HTTP 500; web results supplied candidates instead. Fuzzy CV/ATS/application queries also returned unrelated skills, which were filtered from the recorded candidate list.

The repository-level inventory (`docs/cv-kit-research-inventory.json` in the source repository) pins canonical repository case, commit SHA, exact paths, license metadata/root notice paths and hashes of fetched files. Search results (`docs/cv-kit-search-results.json` in the source repository) record queries and additional candidates; unreviewed candidates are explicitly pending, not adopted. These repository links are supplemental; this installed research file remains self-contained.

## Original design decisions

- Keep one schema-valid master and separate job/evidence inputs; never mutate master data when selecting/reordering facts.
- Separate deterministic layout from host-model drafting. Expose reviewed source references, unsupported requirements, ambiguous dates and missing metrics; numeric-token checks cannot prove semantic truth.
- Produce both documents from one evidence base. Verify company assertions or omit them. Regional/language/length choices are explicit user preferences, not inferred qualifications.
- Keep LaTeX, schema, runtime and runnable sanitized examples inside the installed directory; basic rendering uses Python standard library. Compilation is an explicit dependency and cannot be claimed when skipped.
- Measure PDF extraction/field association separately from relevance. Upstream match estimates, prompts and install counts are not measured ATS scores or browser autofill tests.
